# 基于 BTC 的稳定币研究 · Research on BTC-Based Stablecoins

从第一性原理出发，系统论证一种基于 BTC、以自由能（焦耳）为锚的非托管稳定币（J-ST）的理论自洽性与实证基础。全文由四篇递进研究合并而成：动机 → 理论 → 设计 → 实证。

A first-principles study arguing the theoretical self-consistency and empirical basis of a BTC-based, free-energy-anchored (joule) non-custodial stablecoin (J-ST). The paper merges four progressive studies: motivation → theory → design → empirics.
